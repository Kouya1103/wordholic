# ことのは英単語帳 — 外部APIを使わない版

このアプリには有料APIへの通信、課金・決済機能、有料クラウド保存はありません。Python 3.10以上の標準ライブラリのみで、このPC内のSQLiteへ保存します。環境変数や画面からAPIキーを渡しても有料AIには接続できません。辞書・音声の自動取得も廃止しました。

端末の購入費・電気代・通信費、利用者が別途契約する会話型AI等の費用はアプリの管理外です。「あらゆる費用が絶対にゼロ」という保証ではなく、アプリ自身が従量課金・サーバー契約を必要としない設計です。

## 起動

このフォルダで次を実行し、http://localhost:8765 を開きます。

```bash
python3 app.py
```

初回だけターミナルの初期設定コードでアカウントを登録します。以後はログインして利用します。終了はCtrl+C。初期コードは登録前に再起動すると変わります。既存データは初回登録時に引き継がれ、元の vocabulary.sqlite3 は変更しません。学習データ・音声・ログイン情報の保存先は account-data/ です。

## 会話型AIで教材を作って取り込む

1. 「マイ単語帳」から [教材作成の命令文](static/material-prompt.txt) をダウンロードします。
2. 会話型AIへ命令文と単語一覧またはCSVを渡します。末尾の難易度を必要に応じて変更してください。個人情報・APIキー・ログイン情報を渡さないでください。
3. 生成された kotonoha-materials.json をダウンロードします。ファイル作成できないAIの場合は、JSONコードブロックの中身だけをUTF-8で保存します。外部AI側の有料機能は使わないでください。そのサービスの利用条件・無料枠はアプリでは管理できません。
4. アプリの「教材JSON」で選択し「内容を検証・確認」を押します。
5. 追加・更新・重複スキップの一覧を確認して保存します。英語・解説の内容自体はファイルも読んで確認してください。

[取り込み可能な完成例](static/material-example.json)も同梱しています。試す場合、improveは同梱語なので、既定ではスキップします。「更新する」を選ぶと教材を置換します。

### 教材ファイルの仕様

- UTF-8（BOM可）のJSON、最大2MB、1〜1000カード。
- 最上位は format: "kotonoha-materials-v1" と words の2項目だけ。
- 各カードは word, level, pos, meaning, aliases, example, translation, synonyms, forms, collocations の10項目。
- levelはbasic/standard/advanced。posは名詞・動詞・形容詞・副詞・前置詞・接続詞・代名詞・間投詞のいずれか。
- aliasesは0〜20件。synonyms/formsは0〜10件、collocationsは1〜10件。
- synonymsの要素はword/difference/example/translation。formsはword/description。collocationsはphrase/meaning/example/translation。
- 各項目の文字数、意味・例文・和訳の必須条件などは命令文を参照してください。
- 未知の項目・欠損・不正な型・同一word＋posの重複・重複JSONキーを拒否します。一部だけ保存せず、ファイル全体を検証後に1トランザクションで保存します。
- 検証は形式の確認です。教材の英語・意味・別解・品詞の正確さは保証できません。保存時は「教材JSON・未校閲」と表示します。

### 重複・教材更新・下書き

既定は同じ単語＋品詞をスキップ。更新チェックを付けると教材本文と難易度を置換しますが、復習日・正解履歴・習得判定・音声は保持します。意味を別の語義へ変更すると古い習得判定と対応しなくなるため、同じ語義の解説補完に使ってください。

学習中の問題セットに含まれる語は更新できません。まず学習を完了してください。単語・品詞の異なるカードは別扱い。同じ単語・同じ品詞の複数語義は独立カードとして区別できません。

CSVで保存した補完待ちは、同じ単語・同じ品詞の教材が取り込まれたときに解消します。品詞未設定の下書きも解消します。別品詞の下書きは保持します。

JSONバックアップは教材とは別形式です。教材アップロードでアカウントや学習履歴を上書きすることはありません。

## 継続して使える学習機能

- CSV取り込み（UTF-8/Shift-JIS、2MB・1000行まで）、同梱36語、難易度別の教材選択。
- 最大100語の基本問題と、間違えた語を正解まで繰り返す追加復習。
- 復習期限を優先し、日をまたぐ正解で1・3・7・14・30・60・120・240・365日の復習間隔へ。不正解は翌日へ。
- 英語→日本語、日本語→英語の双方向テストと、方向別の初回回答による習得段階。
- 「英語→日本語は正解、日本語→英語は不正解」なら「理解語彙だが、まだ使用語彙ではない」。
- 品詞選択の一致、登録済み別解による採点、明確な文字重複・入れ替えの入力ミス確認。
- 保存済みの意味・例文・類義語の使い分け・語形・コロケーション・音声の再利用。
- 解説で見た関連語を原則10問程度後ろへ回す調整（候補が不足する場合は可能な範囲）。
- ローカルのログイン、学習中断・再開、データのJSON書き出し。

## 費用を伴う依存をなくしたことでできなくなること

1. アプリ内で未知の単語・解説を生成したり、100語へ自動補充すること。会話型AIで教材を作って手動取り込みしてください。
2. 未登録の日本語回答を意味から柔軟に正解とみなすこと。登録済みの意味・別解で採点します。別解が不足すると妥当な回答も不正解になります。品詞も選択・登録データに基づく判定で、自由な文の文法解析ではありません。
3. 自由な英文の自動採点と、それに依存する「例文の中で使える」「習得済み」の新規自動認定。既存の判定履歴は残します。例文の読み込み・表示は可能です。
   旧版で未完了の例文作成問題は起動時に日本語→英語へ切り替え、次回の出題設定は自動へ戻します。過去の採点履歴は変更しません。
4. 文脈が必要な変換ミスの広い検出。明確な文字の重複や入れ替わりなどの限定的な確認だけになります。
5. 新しい発音音声の自動取得。すでに保存済みの音声は再生できます。未保存なら辞書リンクを手動で開いて確認します。教材JSONに音声バイナリやURLを追加しないでください。
6. 外出先からの自動同期・常時稼働の公開サービス。この版の通常運用はこのPC内に限定します。クラウドやドメインを契約しません。スマートフォンのlocalhostではこのPCを開けません。

## ログインとバックアップ

初回登録は本人の1アカウントのみ。ログインは30日間、ログアウトはその端末のセッションを失効させます。パスワード復旧はサーバー側で次を実行します。入力したパスワードは画面に出ません。

```bash
python3 app.py --reset-password ユーザー名
```

全端末のセッションが失効します。メール認証・SNSログイン・MFA・一般公開登録はありません。

アプリを停止して account-data/ をフォルダごとコピーすると、ログイン情報・学習データ・音声をバックアップできます。別のPCへ移す場合もPythonとアプリが必要です。同時編集した複数コピーの自動マージはありません。JSON書き出しは閲覧用で、履歴・音声の完全復元用インポートは提供していません。

## 検証

